# BMI_CALCULATOR
A BMI (Body Mass Index) Calculator is a Python application that calculates a person's BMI based on their weight and height. It then classifies the result into categories such as Underweight, Normal, Overweight, and Obese.  
The advanced BMI Calculator uses a Tkinter GUI for easy interaction, SQLite to store users' BMI records, and Matplotlib to display BMI trends over time. It also includes input validation and error handling.
